# KBG Gündem — Mesleğin Ortak Sesi

Kuaför, berber ve güzellik salonları için bağımsız meslek gündemi, haberler ve sektörel kampanyalar.

Bu depo KBG Gündem web sitesinin kaynak kodlarını içerir. Yayın altyapısı GitHub + Cloudflare Pages + Pages CMS olarak hazırlanmıştır.

Kurulum: `npm run build` (çıktı: `dist`), ardından Cloudflare Pages üzerinden GitHub deposunu bağlayın. Yönetim: https://app.pagescms.org/.

Resmî KDV kampanyası başvurusunun durumu doğrulanmadan başvuru veya imza toplandığı ilan edilmez.
